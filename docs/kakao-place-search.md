# 카카오 장소 검색 설정

2026-10-12 청모 앱(ID: 1604853)을 확인했다. 키 확인 경로는 카카오 개발자 콘솔 → 앱 → 청모 → 앱 → 플랫폼 키 → REST API 키다.

앱 등록 시 기본 REST API 키가 생성된다. 로컬 서버에는 해당 키를 Windows DPAPI로 암호화하여 `data/kakao-rest-api-key.dpapi`에 저장했다. 파일 권한은 현재 Windows 사용자로 제한하며 `data/`는 Git에 포함하지 않는다. 평문 임시 파일은 제거했다. 키 값은 문서, 프런트엔드, 콘솔 출력에 기록하지 않는다.

`scripts/env.ps1`은 외부 `KAKAO_REST_API_KEY`가 없으면 현재 Windows 사용자로 암호화된 키를 읽어 서버 프로세스 환경 변수로 전달한다. `scripts/run.ps1`으로 다시 실행할 때도 적용한다. 다른 PC나 배포 서버에서는 해당 파일을 복사하는 대신 배포 환경의 비밀 관리 기능으로 `KAKAO_REST_API_KEY`를 지정해야 한다.

키만 연결하고 카카오맵 사용 설정이 OFF이면 카카오 응답은 HTTP 403, `disabled OPEN_MAP_AND_LOCAL service`다. 콘솔 → 제품 설정 → 카카오맵 → 사용 설정을 활성화해야 한다. 2026-10-12 사용자 승인 후 콘솔에서 ON 상태와 청모 앱에 일간 무료 쿼터가 제공됨을 확인했다. 서버 API에서 성수 카페·식당 각각 15개 결과를 반환했고, 브라우저에서 카페 검색 결과 표시를 확인했다.

## 과금 (2026-10-12 공식 문서 기준)

- 현재 구현은 카카오의 ‘키워드로 장소 검색’ API를 사용하며, 식당·카페는 이 API의 카테고리 필터로 구분한다. 두 종류가 같은 키워드 검색 무료 제공량을 사용한다.
- 해당 API는 일간 100,000건 무료. 유료 사용 설정 시 무료 제공량을 넘는 호출은 건당 2원, 부가세 10% 별도다. 예를 들어 하루에 110,000건을 호출하면 유료 10,000건 × 2원 = 20,000원, 부가세 포함 22,000원이다. 요금과 쿼터는 변경될 수 있다.
- 앱 콘솔의 ‘유료 API → 일반’에서 비즈월렛 미연결과 카카오맵 유료 사용 ‘사용 안 함’을 확인했다. 무료 제공량을 초과하면 자동 결제되는 대신 요청이 제한된다(HTTP 429). 유료 이용에는 별도로 비즈월렛 연결과 유료 사용 설정이 필요하다.
- 검색 버튼을 누를 때 API 요청하며, 결과 15개는 검색 요청 1건이다. 로컬과 배포 서버에서 같은 카카오 앱을 사용하면 사용량은 합산된다.

출처: [공식 쿼터·요금](https://developers.kakao.com/docs/ko/getting-started/quota), [유료 API 안내](https://developers.kakao.com/docs/ko/app-setting/paid-api), [카카오맵 이용 정책](https://developers.kakao.com/docs/ko/kakaomap/common).

카카오 로그인 활성화, 클라이언트 시크릿, 리다이렉트 URI 설정은 장소 검색과 별도다.

## 지역 드롭다운
장소 찾기에 대지역 17개와 연동 소지역 선택을 추가했다. 빠른 선택은 서울 강남·성수·공덕·홍대·여의도·잠실·종로, 부산 서면·해운대, 대구 동성로의 10개 예시이며 통계상 순위는 아니다. 모임의 기존 지역을 가능한 경우 초기 선택으로 반영한다. 소지역 미선택 시 대지역 전체를 검색하며 추가 검색어로 목록 밖 동네나 음식 종류를 입력할 수 있다. 서버에는 대지역·소지역·추가 검색어를 합친 q와 장소 종류만 전송한다.

검증: 빠른 선택 10개 확인, 부산 서면 선택 시 대·소지역 동시 반영, 대지역 변경 시 이전 소지역 초기화, 서울 공덕 식당 15개 검색 결과 표시. 390px 화면 가로 넘침 없음 및 브라우저 오류 로그 0개. 로컬 jar 재빌드·재시작 완료.
UI 문구 개선: 시·도 / 동네로 변경. 서울 강남·성수·홍대·잠실·여의도 5개 버튼으로 간소화. 클릭 시 서울과 해당 동네를 반영하며 드롭다운 변경 시 버튼 표시도 동기화한다. 서울 공식 관광 사이트 지역 분류와 기존 모임 동네 목록을 참고한 추천이며 통계상 인기 순위는 아니다. 참고: https://korean.visitseoul.net/attractions?curPage=1
시·도와 동네에 기타 · 직접 입력 추가. 기타 선택 시 해당 입력칸을 표시하고 필수로 받는다. 빠른 선택 기타 버튼은 현재 시·도를 유지하고 동네 직접 입력으로 이동한다. 직접 입력값은 검색어에 반영하며 목록 선택 복귀 시 숨겨진 입력은 검색에서 제외한다.
캐시·네이버 리뷰순·청모 관련 글 비동기 연동은 [장소 검색 확장 안내](place-discovery.md)를 참고한다. 기존 카카오는 대체 검색으로 유지한다.
