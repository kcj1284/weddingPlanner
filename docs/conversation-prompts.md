# 프로젝트 요청 프롬프트 기록

기준일: 2026-10-08 (한국 시간). 이 대화에서 사용자가 요청한 내용을 순서대로 정리했다. 시스템·개발자 지침, 도구 내부 출력, 인증 정보는 포함하지 않는다. 화면 컨텍스트와 HTML 공백 엔티티는 정리했고, 본문과 명령의 의미는 유지했다. 초기 개발 방식에서 최종 요구사항까지의 변경 이력을 보여주는 기록이다.

## 1. 헌장과 최초 명세

```bash
$speckit-constitution 프로젝트 개발 원칙을 작성해줘
$speckit-specify 웨딩 플래너 서비스의 요구사항을 정의해줘
```

```text
ocs: establish constitution v1.0.0 and wedding planner specification
```

```yaml
docs: establish constitution v1.0.0 and wedding planner specification
```

## 2. 모바일 청모 서비스 개발

> 지금부터 모바일 사이트를 만드려 해.
>
> 기본적인 컨셉은 한국의 청첩장 모임 (청모)를 위한 사이트를 만들 예정이고
>
> 나는 springboot 및 js, oracle을 사용하는 편인데 개발 언어는 어떤게 좋을지 너가 스펙에 맞게 고려해서 개발해줘.
>
> 사이트의 기능은
>
> 1. 약속 잡기 > 청모의 경우 여러사람이 특정 장소에 모여서 진행을 해야하다보니 어디서 만날지, 몇일 몇시에 만날지 투표하는 기능이 있어야해.
> 2. 예약 가능한 식당이나 카페 찾기 > 해당 기능은 청모의 host를 위한 기능이야.
> 3. host와 guest 분리 > 청모를 여는 host와 참여하는 guest가 분리 되어야해.

## 6. 코드 입력을 통한 게스트 참여

> guest의 경우 초대받은 모임을 클릭 시 특정 초대코드를 입력하면 들어갈 수 있게 하고싶어

> 초대코드가 너무 길어 6자리 정도의 숫자와 영문을 섞은 구조로 가고 헷갈리지 않게 영문은 대문자만 쓰자
