> 어떤 버전으로 설치하면 될까?

> Oracle AI Database 26ai Free는 클라우드 방식이야 아니면 로컬만을 위한 셋팅이야?

최종 DB 선택은 PostgreSQL이다. Oracle 19c 경험을 고려한 비교 후 비용과 실제 배포 방향을 포함해 PostgreSQL 전환을 승인했다. 인증 과정의 기기 코드와 자격 정보는 기록하지 않는다.
