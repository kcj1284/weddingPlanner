# 카카오톡 단체방 초대

호스트의 초대하기에서 **단체 초대 링크 만들기 → 카카오톡 단체방 공유**를 사용한다. 카카오톡에서 보낼 친구 또는 단체방을 사용자가 직접 선택한다. 서비스는 단체방 목록을 수집하거나 자동 발송하지 않는다. 기존 개인별 6자리 초대코드는 유지한다.

단체 URL은 `/?group=<256비트 임의 토큰>`이다. 링크를 가진 사람은 가입 없이 이름으로 참여할 수 있다. 같은 이름을 입력해도 다른 세션의 참여자는 별도 계정과 투표를 가진다. 기존 게스트 세션이 같은 모임에 참여 중이면 그 신원을 유지한다. 신규 참여 시 개인 bearer 링크를 발급하고 주소를 `/?guest=...&meeting=...`으로 바꾼다. 개인 주소는 재접속용이므로 다른 사람에게 공유하지 않는다. 세션과 개인 주소를 모두 잃고 공통 링크로 다시 들어오면 새 참여자가 될 수 있다.

공통 링크는 30일 유효, 모임당 활성 링크 최대 20개, 참여 최대 100명이다. 호스트는 단체 초대 닫기로 새 참여를 차단한다. 이미 참여한 친구와 투표·개인 링크는 유지하며 개인 초대 취소로 접근을 별도로 회수할 수 있다. 그룹 토큰은 DB에 해시만 저장하므로 호스트가 화면을 새로고침하면 원문을 다시 제공하지 않는다. 복사한 링크를 보관하거나 새 링크를 생성한다.

Flyway V4는 group_invite 테이블을 추가한다. 미인증 공개 미리보기와 참여 API에도 기존 IP 시도 제한을 적용하고, 참여 POST는 CSRF 검증·세션 교체를 유지한다. 이름으로 다른 사람의 신원을 복구하지 않는다.

## 카카오 설정

기존 청모 앱 1604853의 JavaScript 키를 사용한다. 키는 ignored data 폴더의 DPAPI 파일에 저장하고 실행 환경에서 KAKAO_JAVASCRIPT_KEY로 읽는다. 프런트에는 공개용 JavaScript 키만 전달하며 REST API 키나 어드민 키는 전달하지 않는다.

2026-10-13: JavaScript SDK 도메인과 제품 링크 웹 도메인에 `http://localhost:8080`을 등록했다. SDK 2.8.3의 텍스트 공유를 사용한다. CSP에는 카카오 SDK의 CDN과 공유에 필요한 정확한 호스트만 허용한다. 배포 시 실제 HTTPS 도메인을 두 설정에 추가하고 해당 주소에서 링크를 만든다.

SDK가 없는 환경에서는 모바일 기본 공유 메뉴를 사용하며, 공유 메뉴가 없으면 초대 문구를 복사해 카카오톡에 붙여 넣을 수 있다. 전송 대상 선택과 최종 전송은 사용자가 수행한다. 로컬 링크는 다른 기기의 localhost로 열리므로 실제 친구 초대에 사용할 수 없다.

## 검증

전체 자동 테스트 42개 통과. 공통 링크 다중 참여의 신원·투표 분리, 개인 링크 재접속, 동일 게스트 세션 재참여, 단체 취소 후 신규 차단·기존 참여 유지, 호스트 권한과 만료·빈 이름 검증을 포함한다. 브라우저에서 공통 링크 생성과 이름 참여·개인 링크 전환 및 SDK 로딩을 확인했다. 내장 브라우저에서는 공유 버튼 클릭 후 별도 대상 선택 팝업을 관찰하지 못했으며 실제 카카오톡 메시지는 전송하지 않았다. 일반 브라우저 또는 카카오톡 모바일 환경에서 최종 대상 선택·전송을 확인해야 한다.
