# 아이디·비밀번호 생성 정책

확정일: 2026-10-13. 회원가입 및 비밀번호 재설정에 적용한다. 기존 계정의 아이디·비밀번호는 로그인 때 새 생성 규칙으로 재검사하지 않는다.

| 항목 | 정책 |
|---|---|
| 신규 아이디 | 5~20자, 영문 소문자·숫자·밑줄 `_`·하이픈 `-` |
| 아이디 중복 | 기존 아이디와 중복 불가. 공백·한글·대문자 불가 |
| 새 비밀번호 | **8~64자**, 유니코드 문자 기준으로 계산 |
| 허용 문자 | 한글·영문·숫자·공백·특수문자·이모지 |
| 조합 | 영문/숫자/특수문자 조합 강제 없음 |
| 반복·연속 | 연속 숫자·문자, 같은 문자·단어 반복을 이유로 거부하지 않음 |
| 확인 입력 | 회원가입·재설정에서 비밀번호 확인과 일치해야 함 |
| 기존 계정 | 기존 3~30자 아이디와 BCrypt 비밀번호 로그인 유지. 재설정 시 새 정책 적용 |

예: `12345678`, `aaaaaaaa`, `wordword`는 8자이므로 허용한다. 이런 값이 길이 조건을 만족한다는 의미이며 강도를 보증하는 것은 아니다. 7자 또는 65자 비밀번호는 거부한다. 아이디·비밀번호를 자동으로 자르거나 공백을 제거하지 않는다.

## 조사 근거와 선택

- [네이버 개인 아이디 가입 안내](https://help.naver.com/service/5640/contents/973?lang=en&osType=COMMONOS)의 5~20자·소문자·숫자·`_`·`-` 사례를 아이디 생성 정책에 채택했다. 모든 서비스의 공통 표준이라는 뜻은 아니다.
- [NIST SP 800-63B-4](https://pages.nist.gov/800-63-4/sp800-63b.html)와 [OWASP 인증 가이드](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)는 단일 요소 비밀번호 인증에 최소 15자, 긴 비밀번호 허용과 문자 조합 비강제를 안내한다. 사용자가 최소 길이를 **8자**로 명시하여 그 요구를 우선했다. NIST 전체 요구사항을 준수한다고 주장하지 않는다.
- 요청대로 연속·반복 패턴 거부를 도입하지 않았다. 이번 정책에는 비밀번호 사전·유출 여부 검사도 포함하지 않는다.

## 구현과 검증

서버 `CredentialPolicy`와 브라우저 `credential-policy.js`로 같은 길이·문자 기준을 적용한다. 가입 API 및 재설정 서비스에서 재검사하여 브라우저 검증 우회를 막는다. 현재 비밀번호 확인과 로그인은 기존 자격정보에 대한 검증이므로 새 생성 규칙을 강제하지 않는다.

BCrypt의 72바이트 제한으로 긴 한글·이모지 비밀번호를 처리할 수 없어 신규 저장에는 PBKDF2-HMAC-SHA256, 임의 솔트, 600,000회를 사용한다. V7에서 해시 컬럼을 256자로 확장한다. DelegatingPasswordEncoder가 새 형식을 구분하고 기존 접두사 없는 BCrypt도 검증한다. 기존 해시를 일괄 재작성하지 않는다. [OWASP 저장 가이드](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html), [Spring Security 저장 가이드](https://docs.spring.io/spring-security/reference/features/authentication/password-storage.html).

회귀 검증: 잘못된 아이디·짧은 비밀번호 거부, 8자 연속·반복 허용, 64자 한글 저장과 끝 문자 구분, 65자 거부, 이모지 문자 계산, 이전 BCrypt 로그인. 서버 테스트와 브라우저 화면 기록은 개발 요약에 갱신한다.

검증 결과: 전체 자동 테스트 58개 통과, 로컬 패키지 빌드·실행 성공. 가입·재설정 화면은 고정 규칙 설명 대신 입력 중 미충족 조건을 빨간색으로, 충족 상태를 초록색으로 표시한다. 빈 필드 포커스에는 중립 안내를 제공하고 비밀번호 수정 시 확인 입력을 다시 검사한다. 모바일·데스크톱 화면과 검증 범위는 [실시간 안내 보고서](live-credential-feedback-20261013.md)에 기록했다.
