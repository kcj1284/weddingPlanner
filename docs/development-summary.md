# 청모 개발 정리

기준일: 2026-10-08 (한국 시간). 한국의 청첩장 모임을 준비하는 모바일 웹 서비스다. 호스트가 모임을 만들고 친구를 초대한 뒤, 참가자가 일정과 장소에 투표하고 호스트가 최종 약속을 확정한다.

## 기술 구성

| 영역 | 구현 |
|---|---|
| 서버 | Java 21, Spring Boot 4.1.1, Spring Security, JDBC, Validation |
| 화면 | HTML/CSS, JavaScript ES module, 모바일 반응형 |
| 로컬 DB | H2 파일 DB, Oracle 호환 모드 |
| 운영 DB 준비 | Oracle JDBC 의존성, Oracle DDL과 설정 프로필 |
| 인증 | 세션·CSRF, 비밀번호 해시, 호스트 OAuth2 Client |
| 장소 검색 | Kakao Local API 서버 연동, 미설정 시 직접 추가 안내 |

사용자가 익숙한 Spring Boot·JavaScript·Oracle을 중심으로 구성했다. 로컬에서는 H2로 실행하며 실제 Oracle 접속은 별도 설정과 검증이 필요하다.

## 구현한 기능

- 호스트 가입·로그인·로그아웃과 카카오·구글·네이버 소셜 로그인 설정. 소셜 로그인 완료 시 제공자 고유 ID에 연결된 호스트 계정을 생성한다.
- 모임 생성·목록·상세 조회와 모임별 호스트/게스트 권한 분리.
- 날짜·시간 및 장소 후보 등록, 복수 선택 투표, 투표 변경·철회, 응답 인원과 득표 표시.
- 호스트의 최종 일정·장소 확정, 투표 마감, 기존 투표를 유지한 재개.
- 호스트 전용 식당·카페 검색, 지도 링크, 직접 장소 추가, 예약 확인 상태와 메모 기록.
- 개인별 초대 링크와 코드 발급, 만료·취소, 가입 없는 게스트 참여. 같은 코드나 링크로 재접속하면 기존 이름과 투표가 유지된다.
- ‘초대받은 모임’ 메뉴에서 비로그인 사용자가 코드 확인 후 이름만 입력해 참여하는 흐름.
- 신규 코드는 `A7K3M9` 형태의 6자리 대문자 영문·숫자 혼합이다. I/O/0/1은 제외하고 영문과 숫자를 모두 포함한다. DB 중복 제약과 재발급으로 중복을 방지한다. 기존 긴 코드·링크도 허용한다.
- 코드 검증과 게스트 세션 생성 요청을 IP당 1분 30회로 제한한다. 초대 취소는 기존 세션의 모임 접근 권한과 해당 게스트의 투표를 제거한다.

예약 가능 여부는 호스트가 업체에 확인한 기록이다. 실시간 예약 재고나 결제·예약 대행 기능은 구현하지 않았다. 초대 코드는 사람마다 발급하며, 코드 소지자가 그 게스트의 권한을 갖는다.

## 화면 개선

Product Design으로 로컬 화면을 점검했다. 아이보리·코랄·세이지 색감을 유지하면서 모바일 안내를 세로로 배치하고, 로그인 후 소개 영역을 줄였다. 모임 목록과 투표 저장 영역을 개선하고 선택 개수·미저장 상태를 표시했다. 입력 글자 크기와 버튼 터치 영역, 대화상자 이름, 키보드 탭 이동도 개선했다. 자세한 점검과 당시 캡처는 [디자인 점검](design-audit.md)에 기록했다.

## 문서와 검증

- 개발 헌장 v1.0.0: [constitution.md](../.specify/memory/constitution.md).
- 최초 웨딩 플래너 명세는 `specs/001-wedding-planner/`에 보관한다.
- 활성 청모 명세·설계·작업 목록: [specs/002-cheongmo-meetup](../specs/002-cheongmo-meetup/).
- 호스트 소셜 로그인과 게스트 초대 설정: [social-login.md](social-login.md).
- 최종 서버 테스트 20개 통과. 권한·CSRF·입력 검증·가입 중복·투표 교체·동시 확정·게스트 세션·철회·기존 코드 호환·6자리 형식·요청 제한을 검사했다.
- 실제 브라우저에서 모임 생성·초대·투표·확정·재개·철회·예약 기록과 모바일 화면을 검사했다. 코드 입력을 통한 무가입 참여 및 기존 투표 유지도 확인했다. 6자리 코드는 호스트 발급 화면에서 확인했다.
- 로컬 빌드와 서버 재시작 완료. H2 파일 DB로 기존 모임·투표가 유지된다.

소셜 제공자의 실제 로그인 왕복, 실제 Oracle 접속, 실제 Kakao 검색 성공, 운영 환경 다중 서버 요청 제한, 계정 복구·데이터 보존 정책·사용성 평가는 별도 검증/후속 범위다. 앱 키는 저장소에 포함하지 않는다.

## 실행

Java 21과 Maven을 준비한 뒤 프로젝트 루트에서 실행한다. `scripts/env.ps1`은 프로젝트 `.tools`의 런타임 또는 시스템 런타임을 확인한다.

```powershell
./scripts/test.ps1
./scripts/run.ps1
```

로컬 주소는 `http://localhost:8080/`이다. `.tools`, 로컬 DB, 로그, 빌드 출력과 환경 변수 파일은 Git에 포함하지 않는다. 상세 환경 준비와 제공자 설정은 [README](../README.md)를 참고한다.
