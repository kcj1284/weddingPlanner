# 모바일 청첩장

2026-10-12 사용자 요청: 바른손카드 셀프 제작 목록을 참고한 모바일 청첩장 제작 기능.

## 사용자 여정과 인수 조건
- 호스트가 청모 메뉴에서 청첩장 제작 화면으로 이동한다. 기존 로그인과 소셜 로그인 세션을 재사용한다. 비회원 게스트는 제작·수정할 수 없다.
- 클래식, 보태니컬, 포토 세 가지 독자적인 템플릿을 선택하고 신랑·신부, 부모님 소개(선택), 인사말, 한국 시간 예식 일시, 예식장·주소·교통 안내, 연락처(선택), 대표 사진과 갤러리 최대 6장을 편집한다.
- 모바일 미리보기가 입력을 반영한다. 임시 저장 후 재접속하면 데이터가 유지된다. 다른 호스트의 데이터는 조회·수정할 수 없다.
- 발행 전 공개 URL은 404로 응답한다. 호스트가 공개 안내를 확인하고 발행하면 임의의 128비트 토큰 URL로 로그인 없이 열람한다. 공개 중 수정은 재저장 즉시 반영한다.
- 발행 취소는 즉시 공개 열람을 차단한다. 청모 투표 참여 코드와 청첩장 공개 URL은 별개이며 청첩장 URL로 투표·모임 개인정보를 열람할 수 없다.
- 공개 화면에서 사진, 예식 안내, 지도 검색, 연락처, 일정 파일 다운로드, 공유·링크 복사를 사용할 수 있다.
- 동시에 편집한 이전 버전의 저장은 409로 거부하고 안내한다. 입력·사진 오류와 저장 실패는 화면에 표시한다.

## 데이터 수명과 범위
### 자유 편집 추가 (2026-10-12)
- 호스트는 표지 자유 편집을 켜고 기본 이름·예식 일시·장소·인사말 및 추가 텍스트를 드래그하거나 X/Y 좌표로 배치한다. 텍스트는 최대 30개, 개당 500자이며 글씨 크기·색·정렬·굵기·글씨체를 선택한다. 이름 등 연동 텍스트는 기본 정보 변경을 반영한다.
- 서로 다른 한국어 글씨체 6종을 자체 호스팅해 제공한다. 표지 높이와 배경색·대표 사진 배경을 선택한다. 자유 표지 아래에는 기존 상세 예식 정보가 유지된다.
- QR 코드를 최대 5개 추가하고 위치·크기·사각/둥근/도트 모듈 및 사각/둥근/원형 프레임을 선택한다. 연결 대상은 현재 청첩장 또는 호스트가 입력한 HTTP(S) URL이다. 아직 저장하지 않은 청첩장의 자동 QR은 저장 안내로 표시한다.
- 자유 편집 결과는 기존 저장·발행·취소와 함께 유지되며 기존 청첩장 JSON은 변경 없이 열린다. 모바일에서도 동일 비율로 배치되고 좌표 입력과 키보드 방향키로 드래그를 대체할 수 있다. QR 조합의 실제 디코딩을 자동 검증한다.

청첩장은 계정이 유지되는 동안 보관한다. 발행 취소는 삭제가 아니라 비공개 전환이다. 사진은 자체 저장하며 외부 이미지 URL을 받지 않는다. 결제·인쇄 주문·방명록·참석 응답·계좌 송금·카카오 SDK 공유는 이번 범위에서 제외한다. 브라우저 기본 공유 또는 링크 복사를 제공한다.

## 검증
### 디자인 점검 후 제작 흐름
- 모바일 제작 화면은 디자인·예식 정보·사진·자유 편집·공유의 5개 단계로 이동하며, 편집을 우선 표시하고 미리보기로 즉시 전환한다.
- 저장 상태와 저장 버튼은 모든 단계에서 접근 가능하다. 필수 입력 오류는 해당 단계와 입력으로 이동해 안내한다. 저장 완료 알림은 자동으로 사라진다.
- 문구·QR 선택 시 설정으로 이동하고 키보드로도 단계 이동이 가능하다. 공개 QR은 스캔뿐 아니라 링크로 직접 열 수 있다. 갤러리 사진은 확대하고 닫아 원래 사진 버튼으로 돌아간다.
- 공개 SVG의 실제 표지 문구·QR 링크가 접근성 트리에 노출된다. 데스크톱에서는 편집과 미리보기를 함께 표시한다.

실제 PostgreSQL을 사용해 소유권, 비회원 게스트 거부, 초안 비공개, 발행·취소, 저장 충돌, 사진 검증, CSRF 및 공개 API 정보 범위를 검증한다. 모바일 브라우저로 제작·발행·공개 열람을 점검한다.

## 축의금 계좌 (2026-10-12 추가)
- 호스트는 신랑측·신부측별 최대 4개 계좌를 입력하며 관계, 은행명, 예금주, 계좌번호를 지정한다.
- 공개 여부는 기본 꺼짐이며 공개하지 않은 계좌는 공개 API 응답에서도 제외한다.
- 하객은 양측 목록을 펼치고 계좌번호를 복사한다. 자동 복사가 불가능하면 번호를 직접 선택하여 복사한다.
- 계좌 공개는 기존 청첩장 발행 범위를 따르며, 기존 데이터에 계좌 정보가 없으면 섹션을 표시하지 않는다.
